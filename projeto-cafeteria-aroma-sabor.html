Cafeteria Aroma & Sabor

Site institucional para uma cafeteria fictícia, com apresentação da marca, cardápio de bebidas e produtos, e seção de contato — desenvolvido como projeto de prática front-end.

Sobre o projeto

O objetivo foi construir uma landing page de cafeteria com identidade visual quente e acolhedora, aplicando boas práticas de estruturação HTML, estilização em CSS e pequenas interações em JavaScript — sem frameworks, para reforçar a base da linguagem.

O que foi praticado

Layout responsivo com Flexbox/Grid, componentização visual de cards de produto, tipografia e paleta de cores consistentes, e organização de código para fácil manutenção.
